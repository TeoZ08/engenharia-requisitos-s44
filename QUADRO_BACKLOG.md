# Quadro Kanban — Grupo S44

**[Abrir o quadro oficial no GitHub Projects](https://github.com/users/TeoZ08/projects/1/views/2)**

O Projeto S44 utiliza um **quadro Kanban dinâmico e público**, diretamente ligado às nove histórias de usuário registradas como GitHub Issues. Não é necessário duplicar as histórias neste documento.

O quadro apresenta as colunas **A Fazer**, **Em andamento** e **Concluído**, além do campo **Prioridade** (Alta, Média ou Baixa). Todas as nove histórias estão inicialmente em **A Fazer**, pois não há comprovação de desenvolvimento concluído.
